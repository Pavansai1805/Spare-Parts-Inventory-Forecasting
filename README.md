
# NewX Services – Spare Parts Inventory Forecasting

## Project Overview
This project focuses on analysing historical vehicle service data to understand spare parts usage patterns and support inventory forecasting for NewX Services.

## Objectives
- Analyse historical service and invoice data.
- Identify spare parts usage patterns.
- Understand demand trends.
- Support better inventory planning and Just-in-Time (JIT) practices.

## Dataset
The project documentation describes a dataset containing 28,484 records and 7 columns.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- MySQL
- Jupyter Notebook
- SQLAlchemy

## Project Workflow
1. Business understanding
2. Data collection
3. Data inspection and cleaning
4. Exploratory Data Analysis
5. Feature engineering
6. Forecasting and evaluation (as implemented in the notebook)
